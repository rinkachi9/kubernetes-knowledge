# Platforms

Ways to get a Kubernetes cluster without building one from scratch: managed services from cloud providers and Kubernetes distributions. Corresponds to the "Platform" category (certified Kubernetes distributions and hosted platforms) of the CNCF Cloud Native Landscape.
