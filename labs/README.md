# Labs

Hands-on material: home lab setups and exercises that combine several areas of this knowledge base. This area is not a chapter of the Kubernetes documentation; it holds practice environments and scripts. When a lab gets scripts, it becomes a directory with a `README.md` (the note) and a `scripts/` directory, as described in the guideline.
